2026 · Headless e-commerce

Monsieur Croissant

A Ukrainian-language online bakery built as a fully headless Shopify storefront, with secure customer login and a cart that responds instantly to fast clicking.

  • Next.js App Router
  • TypeScript
  • Apollo Client
  • GraphQL Codegen
  • OAuth 2.0 + PKCE
  • End-to-end type safety. GraphQL Codegen types every Shopify API call, so schema changes show up as compile errors.
  • Customer login. Shopify Customer Account API with OAuth 2.0 and PKCE, state and nonce checks, secure token exchange and httpOnly cookie sessions.
  • Optimistic cart. Quantity changes show at once. Mutations are debounced and batched in the background, so fast clicks do not create duplicate requests.
  • Fewer re-renders. The cart context is split into three layers and combined with React.memo, useMemo and useCallback. I profiled before and after.
  • Pagination without data loss. Custom merge strategies in the Apollo InMemoryCache keep earlier pages when the next page loads.

Zephra

A complete sneaker store theme: every template, an AJAX cart and collection filters, in Liquid and vanilla JavaScript with no libraries.

  • Liquid
  • Vanilla JS
  • Web Components
  • Section Rendering API
  • CSS
  • Cart without page reloads. Drawer and cart page share one script. Quantity changes are optimistic and sent one after another, and the final state always comes from the server.
  • Filters and product page. Collection filters update the grid, count and pagination in place and fall back to normal navigation on error. Variant changes re-render the product section and update the URL.
  • Editable by the merchant. Colors, logo, free-shipping progress bar and every section are settings in the theme editor. Sections come with presets.
  • Accessible by default. Skip link, screen reader announcements, focus restored after the cart re-renders, and reduced-motion support.

BuildForge

A Shopify theme for a custom PC build and repair shop. It sells products, books visits and collects quote requests in one store.

  • Liquid
  • Vanilla JS
  • Metaobjects
  • Cart attributes
  • Alternate templates
  • Build configurator. The visitor picks a use case, budget and add-ons. The script recommends the best matching build from the collection, or prices a custom build part by part, and fills the quote form.
  • Visit booking. Free time slots come from opening hours, closed days, capacity and booked slots stored in metaobjects. The choice is saved as cart attributes that the order emails read.
  • Forms that are hard to break. AJAX quote and review forms with validation, input cleaning and a honeypot field. Customer reviews are metaobjects.
  • Sales sections. Pricing tabs, before and after results, how it works, FAQ and testimonials, each with its own settings.
